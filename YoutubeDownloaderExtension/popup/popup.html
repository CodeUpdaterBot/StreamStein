Tools

Leave blank to attempt to automatically find & use.

Whisper is not bundled (it requires a local Python install with GPU libraries). Leave blank to auto-detect common installs such as a conda voiceai environment.

To set manually, enter the full command, e.g.
C:\ProgramData\Anaconda3\envs\voiceai\python.exe -m whisper (conda example)
...\Programs\Python\Python311\python.exe -m whisper (standard Python install)

Alternatively, you can use a standalone executable like faster-whisper or similar. For example:
C:\tools\faster-whisper.exe (standalone executable)
